Dapur Kilat — Warung Cepat Saji: a fast-paced cooking game played in a desktop browser. Orders pile up on the board, ingredients wait on the counter, and the clock never stops — grab the right ingredients, assemble each dish mid-rush, and serve the plate before the timer runs out. Keyboard and mouse, no network, plain static files.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
